# Kiosk.ke — "Best POS in Kenya" content cluster

This folder contains the working plan and draft assets for turning **kiosk.ke** into the brand Kenyan shop owners repeatedly encounter when they research, compare, choose, and discuss POS systems.

It follows the brief: one powerful **anchor** page supported by **ten spoke** articles, each targeting a distinct search intent and linking back to the anchor.

## Read these in order

| File | What it is |
|---|---|
| `01-cluster-audit-and-blueprint.md` | The audit of kiosk.ke's existing content, the gap analysis, the final cluster architecture, the internal-linking map, publishing order, and distribution plan. **Start here.** |

## The headline finding

> The brief proposed **11 new assets**. An audit of the live site shows kiosk.ke already publishes **59 articles across 7 series** — including its own "Top 10 POS Systems in Kenya", "Free POS Software in Kenya", "How to Choose a POS System", "POS with M-Pesa", and "Supermarket POS".

So this cluster is **not** an 11-article writing sprint. It is:

- **1 anchor** → strengthen an existing page (not a new URL).
- **6 spokes** → already exist; refresh, differentiate, and re-link them.
- **4 spokes** → genuinely missing; write them from scratch (**drafted in `drafts/`**).

Publishing 11 new articles would cannibalise existing rankings and duplicate content the site already owns. The plan below does the opposite: it consolidates authority into one canonical anchor and fills only the real gaps.

## Guardrails applied throughout

- **No fabricated figures.** Every price quoted is a current kiosk.ke plan price. Competitor pricing is never invented — the anchor brief instead specifies a sourcing process for it.
- **Transparency over hype.** Drafts explain what Kiosk does *and* its honest limits (e.g. M-Pesa cannot be processed with no network). This is the differentiator called out in the brief.
- **Descriptive anchor text.** Internal links vary naturally; the exact phrase "best POS system in Kenya" is not repeated on every link.
- **Stable URLs.** The anchor is a durable, annually-updated guide — the year changes in the title, never the URL.
